## 已完成范围

### 采集与识别

- [x] Rust 端窗口枚举（`windows-sys`）。
- [x] 前台窗口优先排序。
- [x] 返回窗口元数据：`hwnd`、`pid`、`process_name`、`process_path`、`is_foreground`、`z_index`。
- [x] 隐私关键词排除 + 排除应用 / 标题过滤。
- [x] 每轮分析窗口数限制（默认 3）+ 重复窗口跳过。
- [x] **窗口文本采集（UIA）**：`read_window_text` 只读采集控件文本，替代截图；识别链路默认零截图。
- [x] **UIA 噪声过滤**：40+ 浏览器/系统装饰控件 denylist。
- [x] **URL 提取** + 本地预判分类（进程名→分类）。
- [x] 各窗口并发分析（`Promise.all`）。

### AI 集成

- [x] OpenAI 兼容 `/chat/completions`，经 **Rust `chat_completions` 代理**（reqwest，绕过 CORS）。
- [x] 活动分析 / 报告生成共用纯文本模型 `textModel`（默认留空，用户在设置中填写，无需多模态视觉模型）。
- [x] AI 输出开发、会议、文档、沟通、其他五类活动。
- [x] AI 描述简体中文、具体且 ≤20 字。
- [x] 清晰错误映射（401/403/404/429/5xx）+ 失败本地降级分类。
- [x] 「测试 AI 连接」按钮。
