# 墨记本地 MCP 配置

墨记 v0.2.0 提供只读 `stdio` MCP。MCP 客户端按需启动墨记主程序，不开放网络端口，也不提供写入、删除、同步或报告生成工具。

## 获取配置

1. 启动墨记桌面版。
2. 打开「设置 → 本地 MCP」。
3. 选择「复制配置」。
4. 将配置加入支持 `stdio` MCP 的客户端。

界面会根据当前安装位置生成可执行文件和数据库路径。不要把个人路径、数据库文件或活动内容提交到仓库。

配置结构如下，占位符需要替换为设置页显示的实际值：

```json
{
  "command": "<墨记可执行文件路径>",
  "args": ["--mcp"],
  "env": {
    "MOJI_DB_PATH": "<墨记数据库路径>"
  }
}
```

也可以在命令行中使用 `--db <数据库路径>`。`--db` 的优先级高于 `MOJI_DB_PATH`。

## 工具

| 工具 | 用途 | 主要参数 |
|---|---|---|
| `search_activities` | 搜索活动 | `keyword`、`from`、`to`、`limit` |
| `get_activity_summary` | 汇总时间范围内的活动、分类和应用 | `from`、`to` |
| `get_moji_health` | 检查数据库是否可读及最近更新时间 | 无 |

`search_activities` 的 `limit` 范围为 1 至 500。时间参数使用 ISO 8601 字符串。参数无效或数据库不可读时，MCP 返回明确错误，不返回数据库路径或额外活动内容。

## 隐私边界

- MCP 只读取 SQLite，不读取前端 localStorage。
- MCP 不发送网络请求。
- MCP 返回内容可能包含应用名、窗口标题和活动描述。只把 MCP 配置加入可信的本机客户端。
- 退出 MCP 客户端后，对应 `stdio` 进程结束；墨记桌面采集不受影响。
