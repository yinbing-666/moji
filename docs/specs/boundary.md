## 技术边界

### 运行环境

- 操作系统：当前主要支持 Windows 10/11。
- 架构：x86_64。
- 网络：仅 AI API 调用需要联网。
- 存储：当前为 localStorage。

### AI 接口

- 协议：OpenAI 兼容 `/chat/completions`。
- 文本模型：`deepseek-chat`（已移除视觉模型，改 UIA 窗口文本识别）。
- 默认 Base URL：`https://api.deepseek.com/v1`。

### 数据流

```text
Rust 枚举可见窗口
  -> 前台窗口优先排序
  -> 隐私关键词排除
  -> 裁取窗口屏幕区域
  -> base64 PNG
Canvas 压缩
  -> base64 JPEG
AI 分析
  -> JSON { category, app, title, description }
按设置决定是否保留缩略图
  -> Activity
localStorage 保存
  -> React UI 展示、筛选、编辑、导出、报告生成
```

## 已知限制

- 当前窗口截图是按屏幕区域裁剪，被遮挡窗口可能出现“窗口元数据”和“截图内容”不一致。
- 进程识别主要基于 HWND 所属 PID，UWP、WebView 或系统宿主窗口可能仍需要额外解析。
- 多窗口 AI 分析当前仍是串行请求，需要继续优化并发策略或合并请求。
