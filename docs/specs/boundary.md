- [x] 返回窗口标题、进程名、PID、进程路径、Z 顺序等元数据。
- [x] 按关键词排除应用或窗口。
- [x] 通过 UI Automation 读取窗口文本，并调用纯文本模型分析。
- [x] AI 输出活动分类、应用、窗口标题、中文描述。
- [x] 活动记录 localStorage + SQLite 持久化。
- [x] 设置 localStorage 持久化。
- [x] 活动记录搜索、分类筛选、仅看今天。
- [x] 单条活动编辑。
- [x] 单条活动删除。
- [x] 活动记录清空。
- [x] 活动记录 Markdown / JSON 导出。
- [x] 设置 API Key、Base URL、模型名、采集间隔和启动后自动采集。
- [x] 截图缩略图保存开关，默认关闭。
- [x] 截图缩略图放大查看。
- [x] 按日期生成日报。
- [x] 报告复制。
- [x] 报告 Markdown 下载。

## 技术边界

### 运行环境

- 操作系统：当前主要支持 Windows 10/11。
- 架构：x86_64。
- 网络：仅 AI API 调用需要联网。
- 存储：localStorage + SQLite。

### AI 接口

- 协议：OpenAI 兼容 `/chat/completions`。
- 文本模型：用户在设置中填写（已移除视觉模型，改 UIA 窗口文本识别）。
- Base URL：用户在设置中填写，默认留空。

### 数据流

```text
Rust 枚举可见窗口
  -> 前台窗口优先排序
  -> 隐私关键词排除
  -> UI Automation 读取窗口文本
  -> 可选裁取窗口并压缩为缩略图
纯文本模型分析
  -> JSON { category, app, title, description }
按设置决定是否保留缩略图
  -> Activity
localStorage + SQLite 保存
  -> React UI 展示、筛选、编辑、导出、报告生成、质量评分和打印/PDF
```

## 已知限制

- 可选缩略图按屏幕区域裁剪，被遮挡窗口可能出现窗口元数据和缩略图内容不一致；活动识别本身不依赖截图。
- 进程识别主要基于 HWND 所属 PID，UWP、WebView 或系统宿主窗口可能仍需要额外解析。
- UIA 读取使用全局锁串行执行；多个窗口的 AI 请求并发执行。
