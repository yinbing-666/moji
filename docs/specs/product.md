# 产品方向 Spec

> 墨记：本地优先的 AI 工作复盘助手。

## 一句话定位

墨记通过定时截屏和 AI 识别，把一天中分散在不同应用里的工作活动整理成可编辑时间线，并生成结构化日报、周报或月报。

## 核心问题

知识工作者写日报时，最大成本不是排版，而是回忆：

1. 今天做过哪些事。
2. 哪些事情值得写进日报。
3. 哪些沟通、文档、开发、调试需要合并成清晰结论。

墨记解决的是“记录和整理素材”这一段，不替用户编造结果。

## 目标用户

- 需要写日报、周报或工作总结的个人用户。
- 程序员、产品经理、设计师、运营、研究人员。
- 重视本地隐私，不希望工作轨迹进入云端数据库的人。

## 当前核心工作流

```text
启动墨记
  -> 配置 AI 服务和隐私规则
  -> 开始定时截图
  -> 枚举可见窗口并优先分析前台窗口
  -> AI 识别活动并保存到本地 localStorage
  -> 用户筛选、修正、删除活动记录
  -> 生成日报/周报/月报
  -> 复制或下载 Markdown
```

## 设计原则

1. 隐私优先：默认不保存截图，只保存文字活动记录。
2. 本地优先：当前活动记录保存在 localStorage，下一阶段迁移到 SQLite。
3. 可修正：AI 识别结果必须允许人工筛选和编辑。
4. 不编造：报告生成必须基于活动记录，不补充不存在的信息。
5. 轻量：不做团队协作、OA 集成、项目管理系统。
6. 可控：后台、托盘、开机自启等能力必须有明确关闭入口后再实现。
