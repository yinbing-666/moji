# 墨记 v0.2.0 平台与集成设计

## 目标

v0.2.0 在不改变现有 SQLite 数据结构的前提下，补充本地集成、可选同步、数据源扩展和 Windows 桌面系统能力。

所有新增能力遵循以下默认设置：

- 本地 API、MCP、同步、开机自启、全局快捷键和系统通知默认关闭。
- 同步只复制和合并数据，不删除源数据。
- 第三方数据源不加载动态链接库，也不能直接写入 SQLite。
- 有 LLM 和无 LLM 模式共用相同的数据源、同步和导出能力。

## 本地只读 API 与 MCP

HTTP API 和 MCP 共用 Rust 只读查询模块。查询模块以只读模式打开 SQLite，不通过前端 localStorage 读取数据。

HTTP API 保持现有边界：

- 只监听 `127.0.0.1`。
- 默认关闭。
- 使用区分大小写的 Bearer Token。
- 只提供健康状态、活动查询和时间汇总。

MCP 使用独立 `stdio` 进程，不开放网络端口。首个版本提供以下工具：

- `search_activities`：按时间、关键词和数量限制查询活动。
- `get_activity_summary`：按时间范围统计活动数、时长、分类和应用。
- `get_moji_health`：返回数据库可读状态和数据更新时间，不返回隐私内容。

MCP 配置只记录可执行文件路径和本地数据库路径。文档不得包含用户的真实数据目录或访问令牌。

## 可选同步

同步目标为用户选择的本地文件夹。该文件夹可以由 OneDrive、坚果云、Syncthing 或其他工具继续同步，墨记不接入云账号。

同步文件使用带版本号的加密快照格式。用户设置同步密码后，墨记才允许创建或读取快照。密码只保存在当前设备，不写入同步文件。

同步规则：

1. 导出当前 SQLite 活动和报告历史的逻辑快照。
2. 使用稳定 ID 合并其他设备的快照。
3. 相同 ID 以更新时间较新的记录为准；缺少更新时间时保留本机记录并报告冲突。
4. 合并前创建数据库备份。
5. 同步失败时不修改当前数据库，界面显示失败原因和最后成功时间。

v0.2.0 不提供远端删除传播、云账号、后台服务器或多人协作。

## 插件化数据源

Rust 后端提供 `ActivitySource` 接口和数据源注册表。数据源只能返回标准化活动，不直接访问数据库。

内置数据源包括：

- `window`：当前设备的前台窗口和可选文本采集。
- `activitywatch`：内置 ActivityWatch 事件。
- `json_file`：用户主动选择的 JSON 文件。

数据源统一返回 ID、时间、应用、标题、描述、时长和可选上下文。导入前执行现有归一化、去重和分类规则。

v0.2.0 不执行第三方 DLL、动态库或任意脚本。后续版本可以在独立进程和明确权限模型完成后开放第三方数据源。

## 平台边界

v0.2.0 只支持 Windows 10／11 x64，不提供 macOS 或 Linux 安装包。Windows 版本提供前台窗口元数据、UI Automation 窗口文本、空闲与锁屏检测、内置 ActivityWatch、开机自启、全局快捷键和系统通知。

采集能力不可用时，应用继续提供导入、回溯、报告、同步和 MCP。采集健康中心必须显示具体限制，不把降级状态显示为正常。

## 桌面系统能力

- 开机自启：使用 Tauri 官方 autostart 插件，默认关闭。
- 全局快捷键：使用 Tauri 官方 global shortcut 插件，默认关闭；首个快捷键用于显示或隐藏主窗口。
- 系统通知：使用 Tauri 官方 notification 插件，默认关闭；仅在采集异常和报告生成完成时通知。
- 快捷键注册失败时保持应用可用，并在设置页显示冲突原因。
- 通知权限被拒绝时不重复请求，设置页提供当前状态。

## 专属 PDF 导出

报告页增加「导出 PDF」操作。应用使用专用 A4 模板生成 PDF，并通过原生保存对话框选择目标路径。

PDF 包含：

- 墨记标识、报告类型、日期和生成方式。
- 关键指标、分类分布和应用排行。
- 报告正文、行动项和风险项。
- 页码和生成时间。

PDF 生成不依赖浏览器页面或外部服务。生成失败时保留报告内容，界面显示可恢复的错误信息。

## 数据与安全边界

- 不修改现有 SQLite schema。
- 不把 API Key、同步密码、活动原文或数据库提交到仓库。
- 同步文件不得使用明文 JSON。
- MCP 和 HTTP API 只读，不提供写入、删除、同步或报告生成工具。
- JSON 文件数据源必须由用户主动选择，不监视任意目录。

## 验收标准

- HTTP API 与 MCP 对相同时间范围返回一致的活动数和汇总结果。
- 错误 Token、无效 MCP 参数和不可读数据库均返回明确错误，不泄露数据库路径或活动内容。
- 加密快照无法以明文读取；错误密码不修改数据库；重复同步结果保持不变。
- 三个内置数据源经过统一归一化和去重测试。
- 开机自启、快捷键和通知可以独立启停，重启后设置保持一致。
- PDF 可以在应用内导出，中文、分页、指标和正文可读。
- Windows 10／11 x64 完成真实桌面验收。
- 通过 `npm run test:features`、`npm run typecheck`、`npm run build` 和 `cargo test --locked`。

## 发布边界

本地实现与验证完成后，再分别确认以下操作：

1. 提交本地改动。
2. 构建并验收 Windows x64 安装包。
3. 推送远端分支。
4. 创建 `v0.2.0` 标签和 GitHub Release。
