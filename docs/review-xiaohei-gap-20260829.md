## 1. 一句话定位对比

**小黑**：像素证据链 —— 截图→本地 OCR→销毁，赌"屏幕上看得见的都能记下来"，覆盖广但归纳过程是黑箱。
**墨记**：语义结构化 —— 窗口元数据 + UIA 控件文本，赌"结构化字段可归因"，可解释、可修规则，但对 Canvas/Electron 自绘、远程桌面、视频、扫描版 PDF 存在采集盲区。

一句话：小黑是"记录器"，墨记是"分析器"。墨记的真实差距不在采集能力，在**首日价值感和表达力**。

## 3. 关键洞察

1. **热力图 + 概览卡是留存钩子**，不是分析工具。用户装完第一天不会读周报，但会看一眼"我今天是什么形状"。墨记的深度分析（专注/打断/周对照）价值更高，却全部在第 7 天才兑现。
2. **AI 逻辑重构是真正的付费点**。把时间线拼成段落谁都会，难的是判断"哪 3 件事值得写、哪 20 条噪声该丢"。
3. **小黑的隐私叙事强于其隐私实质**。墨记不截图、不 OCR、密码框跳过、可脱敏导出，隐私实际更强，但没有"隐私金字塔"这样的一句话资产。这是**表达差距，不是能力差距**，改起来最便宜。

## 4. 墨记的差异化（必须守住）

- **规则可解释 + 未分类收件箱**：命中哪条规则、哪个字段、哪个关键词全程可查，批量归类还能反哺成规则 —— 小黑的 OCR 黑箱结构上做不到。
- **AFK/锁屏按实际活跃秒计**：小黑的"截图条数"无法区分人在不在。
- **专注/打断分析 + 周计划对照**：从"记录"跨到"改进"，小黑止步于记录。
- **本地 API + MCP**：可被外部 Agent 调用，这是长期最大的结构性优势。
- **无 LLM 降级模式、加密目录同步、脱敏诊断导出**。

## 5. TOP10 建议

**P0（高价值低成本）**
1. **时段热力图**：复用现有 SQLite 聚合，近 3–7 天 × 小时格，首屏可见。
2. **报告 prompt 重构为"重点提炼"**：强制输出「今日 3 个重点 + 产出 + 阻塞」，而非时间线复述。
3. **今日叙事卡**：活跃区间、最长连续专注段、今日主线，一句话可读。
4. **报告生成后可编辑再导出**：不可编辑的日报无法交付。
5. **隐私说明页**：把"不截图/不 OCR/密码框跳过/UIA 只读"写成三层结构，装机首屏和官网都用同一套话术。

**P1（值得跟进）**
6. **采集降级策略**：UIA 取不到控件文本时，仍按进程+标题+时长记录并标注「低置信度」，补齐 Canvas/远程桌面盲区。
7. **报告多模板**：周报向上汇报版 / 个人复盘版 / 简历素材版。
8. **应用别名与图标映射**：`Code.exe` → VS Code，提升报告可读性。

**P2（可暂缓）**
9. 多显示器上下文采集。
10. 商业化外壳（订阅/邀请）—— 先把 P0 做完再谈。

## 6. 风险提醒

- **截图/OCR 是不可逆的边界破坏**：一旦引入，墨记就变成"功能更少的小黑"，同时背上模型体积和 CPU 占用。
- **"AI 呈现放大器"与内容伪造只隔一层**：墨记必须保留报告每句话**可点回原始活动记录**的溯源能力 —— 这恰恰是 OCR 黑箱做不到的，应当作为卖点而非负担。
- **游戏化与通知会侵蚀"低打扰"**：勋章、连续打卡、每日提醒，全部与产品气质冲突。
- **订阅墙不要挡住本地核心功能**：墨记的信任来自"东西在我机器上"，付费墙一旦挡住采集或本地查询，信任叙事立刻崩塌。
