## 一、三层隐私结构

**采集层 · 只读文字，不看画面**
墨记定时枚举可见窗口的进程名与标题，并通过 UI Automation 只读读取窗口内控件文本。默认不截屏、不 OCR、不录屏、不录音；密码框等敏感控件自动跳过。

**处理层 · 默认不出本机，是否用 AI 你说了算**
默认使用本地关键词规则分类，完全不上云。启用 LLM 时，只把允许的进程名、可执行文件名、窗口标题与窗口内文本，发送到你自己配置的 OpenAI 兼容接口；不发送完整本机路径，不发送图像。

**存储层 · 存在本机，导出可控**
活动记录与设置保存在本机 localStorage 与 SQLite，支持 JSON 导入导出、SQLite 备份恢复。脱敏诊断导出不含活动记录、窗口标题、截图或 API 配置值。

## 三、设置页文案

- **隐私排除**：按应用名、窗口标题或进程名关键词排除，命中的窗口不会被采集。
- **上下文采集**：浏览器域名与 IDE 项目名默认关闭；即使开启，也只保存结构化的域名与项目名，不保存完整 URL 与文件内容。
- **锁屏与空闲**：锁屏时立即暂停采集；可设置空闲阈值，超过阈值判定为离开。
- **缩略图与截图**：默认不截屏；仅当你在设置中显式开启后，才会在活动记录里保存压缩缩略图。
- **AI 分析**：关闭时使用本地关键词规则，数据不出本机；开启后才会向你配置的接口发送文本。API Key 以明文保存在本机 localStorage，这是本地信任模型下的取舍。
- **数据保留**：可设 30 / 90 / 180 / 365 天或永久保留；执行清理前会二次确认并先自动备份。
- **导出与备份**：支持 JSON 导入导出与 SQLite 本地备份恢复，文件放在你指定的位置。
- **本地只读 API**：默认关闭，仅监听 127.0.0.1，且需访问令牌。
- **加密目录同步**：使用 AES-256-GCM，只读写你选择的本地目录，无云账号，不连云端。

## 四、FAQ

**1. 会截屏吗？**
不会。墨记默认不截屏、不 OCR、不录屏、不录音，只读取窗口元数据与控件文本。

**2. 数据会传到云端吗？**
不开 LLM 就完全不上云。开启后，文本会发到你自己配置的接口——目的地由你决定，我们不经手、不中转。

**3. 能完全不用 AI 吗？**
可以。无 LLM 模式用本地关键词规则完成分类，功能完整可用。

**4. 密码框会被读取吗？**
不会。UI Automation 采集时自动跳过密码框等敏感控件。你也可以用关键词把整个应用排除在外。

**5. 换电脑数据怎么办？**
用 JSON 导出或 SQLite 备份，把文件手动带到新机器导入。也可开启加密目录同步，用 AES-256-GCM 读写你指定的本地目录。
